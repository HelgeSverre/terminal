# Retained evidence

Reports generated by tests, smoke runs and benchmarks are ignored by default.
Keep the conclusion and enough provenance to assess it; raw output belongs in
local reports or CI artifacts. Test inputs belong under `Tests/Fixtures`, not here.

Before adding evidence, check whether an existing summary already records the
decision. Update it or add one small summary in a dated directory. Include the
tested source commit, command and configuration, result (including failures and
skips), and executable hash for measurements. Link to CI artifacts when useful.
Use `git add -f` with individual selected paths after reviewing their contents.

Keep summaries and machine-readable receipts under 32 KiB each where practical.
A visual proof earns a place only when it demonstrates something a test or
summary cannot; use a cropped image. Keep raw logs, sample streams, screenshots
from intermediate attempts, profiling captures, archives and copied sources
outside Git. A dated directory alone is not a reason to retain a whole run.

## Where to look

- [Current protocol coverage](../docs/protocol-coverage.md) records capabilities,
  tests and known gaps; [conformance](../docs/conformance.md) describes repeatable gates.
- [Library split](library-split-2026-11-14/README.md) records the embedding checks.
- [TUI stress](real-tui-pane-stress/README.md) and [terminal comparison](terminal-comparison-2026-11-10/README.md)
  retain their conclusions and provenance.
- Installation receipts under `distribution-*-evidence/installation.json` are
  also consumed by `dev tui-stress --installed`; keep them with their executable identity.
- Other retained directories are historical summaries, not current acceptance gates.

## Historical raw evidence

The 2026-11-16 cleanup removed 1,056 generated/intermediate artifacts (51.4 MiB)
from the working tree, preserving 175 summaries, receipts and selected proofs
(0.77 MiB before this index). It rewrote no Git history. Older clones keep the
historical objects; reducing a full clone's history size is a separate operation.

The complete pre-cleanup evidence is available at
[commit 3ad91fe](https://github.com/HelgeSverre/terminal/tree/3ad91fe/reports).
Paths in historical summaries and JSON manifests refer to that snapshot when
the raw file is no longer present. Retrieve one file without restoring a directory:

```sh
git show 3ad91fe:reports/path/to/artifact
```

Historical hashes and conclusions are preserved. Relative Markdown links to
removed files now point to the archived version. Ignored local output in other
checkouts was left alone.
