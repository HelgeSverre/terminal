# Lazy indexed payload arena

Baseline 649083c. Scratch only, two production files: TerminalDocument owns representation/accounting/planning bound; DocumentReflow asks that cost query at primary-row planning and alternate-copy reservation. No parser/segmenter/writer fast paths changed.

Representation: lazy [Int] column→one-based arena handle, zero absent; arena Entry contains optional payload and intrusive next-free handle. Each live column owns exactly one entry. Replacement retains its handle; deletion clears Strings and links the hole; insertion reuses a hole before append. Array COW and existing TerminalRowStorage COW retain value semantics. Copy/shift obtains a payload value then assigns it at destination, never copying handles. Int supports the actual Array index domain; direct row APIs do not enforce 4096 geometry, so a UInt16 assumption would be unsound. A >65,535-live-payload test exercises this explicitly.

Work bounds: lookup/replacement/deletion O(1); insertion amortizes arena/index Array growth. First far-column payload initializes its index prefix O(column), bounded by row width. Same-row shifts remain O(columns), not sorted-vector O(columns*payloads). Arena.count is bounded by peak simultaneously live payload count since reset because holes are always reused; index.count by greatest written column+1. Kept capacity can exceed current counts but is charged. Iterating values scans arena high-water slots; key/value iteration scans index prefix. No permanent increase to 24-byte TerminalRowSlot.

Allocation: allocationBytes counts both actual Array capacities, conservative 32-byte buffer headers, all arena holes, and 64 bytes per live payload for up to two String allocation headers. Existing 2*utf8Bytes reservation accounts owned String data; holes contain nil and retain no String. Enlarged TerminalRowStorage fields are included in allocationSlotCost, including the empty lazy owner. Public legacy logical 32+64*logicalCapacity+per-cell-text/link history charge is untouched.

Planning: fresh packed rows reserve four capacity slots per possible payload and per output column, plus buffer/String headers. This is deliberately conservative geometric-growth/allocator-rounding headroom, not RSS. The bound is tested against actual capacities for every supported geometry 1...4096 (single far-column payload) and every dense live count 1...4096. Existing fragmented source rows use actual capacities rather than live-count bounds. Primary output uses the new query instead of sparseCells*384. Alternate copy reserves its existing resource allowance plus the same new-owner bound, covering changed Array growth order. Physical temporary admission can legitimately differ from dictionary baseline; old admission is not forced when storage costs change.

Validation: baseline/candidate use identical assertions. A baseline-only test extension exposes the old planner formula without changing baseline production. Full ownership/emulator/reflow/Unicode suites; fragmentation/reuse, retained snapshot, copy/shift nonaliasing, >65,535 handles, kept empty capacity, logical charges and String release accounting; 4096-column singleton and fragmented COW source/reflow ledger checks. Exact movement/document/transport traces exclude physical admission costs but retain logical charges, cells, revisions, attributes, consumed offsets and replies. Existing reflow tests cover cancellation, pressure, process rejection and resource release.

One candidate and one matched matrix; no timing until explicit release. Build-time results are not comparable because root compilation may overlap.
