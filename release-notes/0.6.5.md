# Helge Terminal 0.6.5

## Performance
- Render ASCII, truecolor, and Unicode output faster with a lower memory footprint.
- Decode Kitty PNG images up to 26× faster and upload Kitty RGBA image data 2× faster.

## Graphics and terminal protocols
- Support Kitty indexed-color animation frames, composition, playback, and promotion.
- Reply to `DECRQSS` queries for `DECSNLS` and `DECSLPP`.

## Reliability and responsiveness
- Sample process arguments for crash recovery in-process via `KERN_PROCARGS2` instead of spawning `ps`.
- Unify mouse, link, and selection hit geometry during fractional smooth scrolling.
- Improve UIKit end-of-line touch selection and make accessibility elements lazy.
- Adopt Swift 6 strict concurrency across the codebase.
