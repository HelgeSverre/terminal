# Helge Terminal 0.6.2

## Links
- Hold Command over a link to see its destination before opening it.
- Keep the destination visible while hovering, including during cursor refreshes.

## Images
- Correct Kitty animation frame composition.
- Support Kitty animation frame deletion and correct frame timing after edits.
- Position and delete relative Kitty images correctly, including Unicode placeholder parents.
- Report supported Kitty graphics features accurately for each action.
- Display images from current Kitty clients using larger chunks and unpadded base64.
- Bound SIXEL command state when processing image data.

## Crash recovery
- Restore windows, tabs, splits and scrollback text after a crash or forced quit.
- Offer to resume an interrupted agent session; nothing restarts until you choose Resume.

## Search
- Add case-sensitive, whole-word and regular-expression search options.
- Support groups, alternation, classes, `{n,m}` repetition and `\d`, `\s`, `\w` in regular expressions, with bounded work.
- Scroll to the matched text instead of a neighboring row.

## Shell integration
- Add Bash and fish integration alongside zsh.
- Jump between commands in scrollback, including after the window width changes.

## Settings
- Add launch profiles, remappable menu shortcuts and theme colors through an importable JSON configuration.
- Choose separate behavior for the left and right Option keys.
- Choose the cursor shape and blinking, or follow the application's requests.
- Add a visual bell that briefly outlines the pane.

## Text and rendering
- Draw curly, dotted, dashed and double underlines, and underline colors.
- Show blinking text when a program requests it.
- Scroll smoothly by fractions of a line.
- Fix stale frames after a resize.

## Keyboard and mouse
- Support xterm modifyOtherKeys and formatOtherKeys keyboard reporting.
- Support pixel-precise (SGR-Pixels) mouse reporting.

## Images and downloads
- Honor stretch and aspect-ratio requests for iTerm2 inline images, and play animated GIFs.
- Offer a file sent by a terminal program as a download: nothing is written until you choose Save and a destination. Several files queue in the pane.
- Keep images in place when text scrolls inside margins.

## Terminal compatibility
- Answer more status queries: DECRQSS settings, DECDSR device reports, DECID and DECRQM for additional modes.
- Add reverse-wrap modes 45 and 1045.
- Fix cursor, erase, rectangle and saved-cursor behavior found by the esctest conformance suite, which now passes 460 of 567 cases.
- Never report a window or icon title back to a program, so output cannot place text on the command line.
- Report the terminal's own name and version through XTVERSION.

## Automation
- Add read-only AppleScript collections for windows, tabs and panes.
- Add AppleScript commands to read pane history, working directory, selection and saved preferences, and to apply a desktop configuration.

## Release builds
- Exclude developer diagnostic launch modes from distributed apps.
- Run tests separately from signing and notarization.
