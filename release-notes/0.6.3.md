# Helge Terminal 0.6.3

## Keep programs running across a relaunch (experimental)
- Relaunch or update the app while the programs in every pane keep running. The windows, tabs and splits come back with the same processes, screens and scrollback.
- Off by default. Turn it on with `defaults write no.helgesverre.terminal KeepSessionsAcrossRelaunch -bool true`, then use Relaunch Keeping Sessions in the app menu. With it on, installing an update keeps the programs running too.
- Images, the selection, search and command marks are not carried over.

## Windows
- Restore nested split sizes exactly when windows are rebuilt.
- Quit when asked a second time while the first request is still closing programs.
