# Helge Terminal 0.6.1

## Integrations
- Register Helge Terminal as a macOS terminal application so tools such as JetBrains Toolbox can discover it.
- Open executable command files in new terminal windows, including when the app is already running.

## Images and updates
- Improve Kitty graphics compatibility with animations, relative image placements, and Unicode placeholders.
- Show version-specific release notes inside the update dialog.

## Embedding
- Add terminal views for SwiftUI and iOS.
