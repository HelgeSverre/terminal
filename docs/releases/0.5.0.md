This release adds a font menu, ligatures and a setting for how emoji
sequences are laid out.

- Settings > Text has a font menu. Obel Mono is still the default. JetBrains
  Mono, Fira Code, Hack and IBM Plex Mono now come with the app, and the
  fixed-pitch fonts installed on your Mac are listed under them. Icons are
  drawn from the bundled symbols font whichever font you choose.
- "Join ligatures" draws `->`, `!=`, `===` and the like joined in fonts that
  have ligatures, such as JetBrains Mono and Fira Code. It is off until you
  turn it on.
- "Join emoji sequences" is on, as before. Turn it off if zsh overwrites its
  prompt while you edit a command line that holds an emoji with a skin tone,
  a flag or a joined emoji: each part then takes its own cells, as zsh counts
  them, and such emoji are drawn in parts. Programs can also switch this
  themselves with mode 2027.
- A bell from a program no longer disappears inside the emulator; the app
  itself still makes no sound.

For developers: the terminal is now a Swift package that other macOS apps
can embed, with a view, a session that runs a process or a custom transport,
and a headless emulator. See `docs/embedding.md`. The interface is new and
may change before 1.0.

Installed copies of 0.4.0 or later offer this update at launch or from
Check for Updates… in the app menu.
