This release adds in-app updates, starts split panes at their real size, and
is the first under the MIT License.

- The app updates itself. It looks for a new version once when it starts and
  when you choose Check for Updates… in the app menu, and installs one only
  after you agree. It never checks on a timer while it runs. Updates are
  signed, and come from this repository's releases. Version 0.3.1 has no
  updater, so this update still arrives by Homebrew or by download.
- A new pane's shell starts on a terminal of the pane's size. It used to
  start at 80 by 24 and be resized, which could leave a stray `%`, a missing
  right-hand prompt or a stray character in a new split.
- Programs that ask for the microphone, camera, contacts, calendars, location,
  photos or control of other apps now get the system's permission prompt,
  naming Helge Terminal, instead of being refused.
- The menu bar and the About window call the app Helge Terminal.
- The code is released under the MIT License.
- Releases are a signed, notarized ZIP. The PKG installer is gone.
