This release runs on Intel Macs and on macOS 14.

- The app is now a universal build: Apple silicon and Intel. On Intel the
  terminal used to stop while starting its renderer.
- The oldest supported system is macOS 14 instead of macOS 15.
- Double-clicking to select a word no longer fails with a limit error when
  several word selections follow each other while the Mac is busy.

For developers who embed the terminal:

- A session starts its child process itself. A host no longer has to
  build, bundle and sign the `TerminalLauncher` helper.
- The Swift package's minimum is macOS 14, on both architectures.

Installed copies of 0.4.0 or later offer this update at launch or from
Check for Updates… in the app menu.
