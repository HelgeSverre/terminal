This release stops asking before programs write the clipboard, and makes
Shift-Enter reach Claude Code and other programs that use the kitty keyboard
protocol.

- Programs that copy through OSC 52, such as Claude Code, tmux and Neovim,
  write the clipboard without an Allow / Deny prompt. The prompt used to
  appear in every tab and pane and again for every copy, and a second copy
  within a second of a prompt was dropped without a word. Size limits stay,
  and programs still cannot read the clipboard.
- Shift-Enter, Shift-Tab and Shift-Backspace are reported with their
  modifier to programs that turn on the kitty keyboard protocol, as in kitty
  and Ghostty. Shift-Enter used to arrive as a plain Return, so Claude Code
  submitted the prompt instead of starting a new line. Enter, Tab and
  Backspace without Shift, and every key in programs that do not use the
  protocol, send the same bytes as before.

Installed copies of 0.4.0 or later offer this update at launch or from
Check for Updates… in the app menu.
