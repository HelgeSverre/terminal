This release makes trackpad scrolling follow your fingers.

- A trackpad scrolls one line for each line height of finger travel, and
  movement adds up across events. Each small trackpad movement used to be
  divided by a fixed amount and the rest thrown away, so a slow swipe did
  not scroll at all and a fast one jumped.
- Programs that read the mouse, such as Claude Code, Vim and less, get one
  scroll step per line instead of one for every trackpad event, however
  small. An event with no vertical movement no longer scrolls down.
- Changing direction or starting a new swipe starts afresh. A mouse wheel
  still scrolls at least one line for each notch.

Installed copies of 0.4.0 or later offer this update at launch or from
Check for Updates… in the app menu.
