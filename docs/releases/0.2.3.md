This release adds familiar tab shortcuts and makes window titles follow the active pane.

- Cmd+1–8 selects a numbered tab; Cmd+9 selects the last tab.
- Cmd+Option+Left/Right moves between tabs, wrapping at either end.
- Background panes can update their own titles without changing the window title.
- Split panes have optional compact titles, a muted color palette, custom hex colors, and configurable inactive dimming.
- Initial window sizing uses the actual font metrics before the first layout.

The project now uses conventional Swift source and test directories. Build inputs,
benchmark failures, and process cleanup have additional validation and regressions.
The README links to a measured Swift–Ghostty comparison with its limitations.
Performance prototypes remain separate from this release.

Download the signed, notarized Apple Silicon app ZIP or installer PKG below.
Requires macOS 15 or later.

```shell
brew install --cask helgesverre/tap/helge-terminal
```

For an existing Homebrew installation:

```shell
brew update
brew upgrade --cask helge-terminal
```
