This release fixes panes that kept the wrong size after a resize, closes a
pane when its shell is left, and brings control sequence handling closer to
xterm.

- A pane no longer stays at its old size when several panes are resized at
  once. Reflowing a resized pane takes memory from one budget for the whole
  app; a pane that found it taken used to drop the resize and beep. It now
  waits and resizes, and a burst of sizes reflows the text once.
- Leaving a shell with `exit` or Ctrl-D closes its pane, and the window with
  its last pane. A shell that fails as it starts stays open so the error can
  be read.
- A reopen that arrives while the app is still launching no longer opens a
  second window.
- Programs are told which terminal they run in, and only that:
  `TERM_PROGRAM_VERSION` is set, and variables that describe the terminal the
  app itself was started from, `TERMINFO` included, are not passed on.
- Device control, start-of-string and privacy-message strings are consumed
  instead of printed, so sixel data, XTGETTCAP and tmux passthrough no longer
  leak onto the screen. CAN, SUB and ESC cancel a control sequence as in
  xterm, and the screen alignment test (DECALN) is implemented.
- Mode queries report the real state of each mode, the extended cursor
  position report keeps its marker, and the device attributes reply no longer
  claims sixel support.
- Kitty graphics accept padded base64 in a chunk that is not the last, which
  is how chafa sends images.
