This release improves output throughput and introduces the new Settings sidebar.

- PTY reads now overlap terminal processing. Read-ahead is bounded to keep
  typing and resizing responsive during continuous output.
- ASCII and CSI parsing, Unicode category lookup, and visible-link detection
  do less repeated work.
- Settings has grouped navigation, yellow accents, and validation that preserves
  unfinished edits across sections.
- The automation guide lists all 12 AppleScript commands, accepted settings,
  return values, errors, and examples.

In paired development-build tests, the shared reader improved short ASCII by
52–55%, long ASCII by 29–30%, ANSI by 31–33%, and Unicode by 16–17%. The full
8.16 GB SQL dump completed in 156 seconds versus 219 while the window moved
and resized. These are measurements on one Mac, not universal speed guarantees.
See the [method and raw results](https://github.com/HelgeSverre/terminal/blob/main/reports/shared-pty-reader-649/README.md).

Experimental row-printing changes are excluded because they regressed long
ASCII output. The released runtime passed the full native suite, UI smoke,
output-flood latency checks, and CI.

Download the signed, notarized Apple Silicon app ZIP or installer PKG below.
Requires macOS 15 or later.

```shell
brew install --cask helgesverre/tap/helge-terminal
```

For an existing Homebrew installation:

```shell
brew update
brew upgrade --cask helge-terminal
```
